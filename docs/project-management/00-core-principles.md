# 项目核心准则

## 项目目标

本项目构建一个基于 Eclipse Theia Platform 的 IDE，并使用开源 pi agent 作为 AI 底层引擎。

## 运行与部署

- 服务端优先运行在 Linux 环境。
- 产品优先提供 Web 端，桌面端与手机端后续处理。
- 明确区分服务端与客户端，AI agent 以服务方式部署。

## UI 与交互

- UI 采用 panel 层级，至少包含 editor、git、agent-chat、terminal、浏览器。
- 同类 panel 只保留一个实例，避免窗口无限切分。
- panel 之间需要具备通信互联能力。
- AI 改动需要可见、可引用，并支持选择定点修改、立即修改或一次性修改。
- AI 执行 bash 需要人可见，日志与运行状态通过回调式通知推送，不采用轮询。
- 浏览器 panel 用于渲染本地 HTML 和简单交互式本地站点，作为 AI 交互的可视化输出。

## AI 架构

- 使用开源 pi agent 作为 AI agent 的底层引擎。
- pi 与 Theia 通过事件流和扩展机制集成，不把 pi 的终端界面作为产品 UI。

## 上游代码

- Theia 通过 npm 包使用，不 fork 核心代码。
- 自有能力通过 Theia 扩展实现。
- 上游版本需要固定并记录。

## 测试

- 以实例测试为核心，覆盖启动、面板、AI 交互、终端交互和本地 HTML 渲染。
