# 开发记录规范

## 目的

开发记录用于保存每次开发过程的目标、环境、操作步骤、结果、问题和决策，保证开发过程可追溯。

## 存放位置

- 开发记录放在 `app/devlog` 目录。
- 每次开发使用一个文件，文件名格式为 `YYYY-MM-DD-主题.md`。

## 记录内容

每次开发记录至少包含以下部分：

1. 目标：说明本次开发要完成的事情。
2. 环境：说明使用的操作系统、工具链和关键版本。
3. 步骤：按顺序记录实际执行的操作。
4. 结果：说明操作产生的实际结果。
5. 问题与决策：记录遇到的问题以及做出的决定。
6. 后续行动：说明下一步需要做的事情。

## 提交规则

- 开发记录需要随代码一起提交到 Git。
- 记录应使用事实描述，不使用未经验证的推测。
- 记录中的路径和命令需要与实际执行内容一致。

## 格式模板

```text
# 主题

日期：

## 目标

## 环境

## 步骤

## 结果

## 问题与决策

## 后续行动
```
